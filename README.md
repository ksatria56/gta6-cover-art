**Vice Cover Studio** — a web app that turns any photo and a caption into GTA 6-style cover art: a multi-panel neon-sunset poster with bold display lettering, a glowing script subtitle, a retro sun and palm silhouettes, exported as a PNG in 1080 × 1080, 1080 × 1350 and 1920 × 1080 — all three in one click.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, your photos never leave the machine. Load up to four photos (or the included samples), pick one of five layouts (Four Corners, Hero + Three, Full Bleed, Snapshot Stack, Film Strip), one of five sunset grades, type the title / subtitle / tagline, drag panels to reposition each photo, scroll to zoom, and export.

Original fan-made artwork tool. Not affiliated with, endorsed by, or connected to Rockstar Games. Fonts Anton and Pacifico are under the SIL Open Font License (see `app/fonts/OFL.txt`).
